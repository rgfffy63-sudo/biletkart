# БилетКарт

ИИ-приложение для подготовки к экзаменам по билетам: карточки в формате Anki, которые нейросеть делает из конспектов студента. Команда TicketAI, группа РПЗС-25-10(26)п.

## Как открыть

- **Сайт:** открой ссылку GitHub Pages этого репозитория. Работает в браузере на компьютере и телефоне, можно установить как приложение (PWA). Регистрация не нужна.
- **Полная версия для ПК:** скачай `BiletKart_source.zip`, распакуй и запусти `1_start_site.bat` (нужен Python 3). В ней есть аккаунты, Pro по промокоду и синхронизация между устройствами.
- **Телефон (Android):** приложение в разработке, проект для сборки APK через Capacitor уже в архиве.

## Нейросеть

В профиле выбери провайдера (Google Gemini, DeepSeek, OpenAI, Claude, OpenRouter, Groq, Mistral или свой) и вставь API-ключ. Ключ хранится только в твоём браузере. Бесплатный ключ Gemini: aistudio.google.com.

## Файлы

- `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, иконки — сайт.
- `BiletKart_source.zip` — исходный код: сайт, сервер на Python, исходники интерфейса, скрипты сборки Android.
